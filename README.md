# BDSnowflake — лабораторные 1, 2, 3 и 4

В репозитории четыре независимые части:

- **Лаба 1 (Snowflake в PostgreSQL)**: `lab1/` → см. `lab1/README.md`
- **Лаба 2 (PySpark ETL + ClickHouse)**: `lab2/` → см. `lab2/README.md`
- **Лаба 3 (Apache Flink Streaming ETL)**: `lab3/` → см. `lab3/README.md`
- **Лаба 4 (Trino ETL + ClickHouse)**: `lab4/` → см. `lab4/README.md`

Каждая лабораторная имеет **свой `docker-compose.yml`**, **свои SQL** и **свою папку `data/`** (данные продублированы для автономного запуска).
